# SpeakShelf · 美式演讲词句本

整理中英文单词、短语和句子，点击听美式示范，将常用表达组成演讲稿逐句跟读。适配电脑和手机，可添加到手机主屏幕。原生静态 PWA，无需登录，无第三方运行时依赖。

## 使用

- 添加或编辑词句，填写中文、英文、分组、音标和练习备注。
- 从 Excel 复制“中文、英文”两列粘贴，或上传 CSV / TSV。相同英文自动跳过。
- 点击卡片右侧朗读。支持收藏、已掌握、搜索和分组筛选。
- 将词句加入演讲稿，调整顺序、语速、重复次数和跟读间隔。
- 在“设置”点击“准备离线示范”。首次在线加载后，网站和 18 条内置示范可离线使用。
- iPhone 使用 Safari → 分享 → 添加到主屏幕；Android 使用 Chrome → 菜单 → 安装应用 / 添加到主屏幕。

## 音源与离线

18 条内置音频为 Microsoft Zira Desktop **en-US** 合成示范，随站点提供。它们是固定的学习参考，并非真人录音或专业发音评测。音频文件约 350 KB。

新增词句优先播放用户上传的示范音频，否则使用浏览器提供的 **en-US** 设备声音。只选择美式声音，不自动换成其他口音。设备没有美式声音时可使用配置好的 ElevenLabs 在线美式语音；该服务需要联网并可能产生费用。

浏览器即时朗读不能由本应用保存成音频；是否能离线取决于所选系统声音。上传的音频保存在本地，可离线播放。支持 MP3 / WAV / M4A / OGG / WebM / AAC / FLAC，单条上限 8 MB，实际解码能力取决于浏览器。手机可能要求再次点击才能继续有声播放；锁屏或切换应用会停止跟读。

## 数据与换设备

词句、收藏、演讲稿、设置及用户音频保存在当前浏览器的 IndexedDB，**不上传 GitHub，不自动云同步**。使用“导出完整备份”，把 JSON 文件发给另一台设备，再在同一网站导入。导入备份会替换当前设备内容，并有确认提示；CSV 词句导入则追加并去重。

请在清理浏览器、换机、卸载前导出备份。浏览器可能清除站点存储；离线缓存不等于永久备份。不要将私人备份提交到公开仓库。

每台设备最多保存 10,000 条词句，自备音频总量约 50 MB，保存前会检查能否完整备份。多个标签页同时使用时，旧页面保存会被拦截并提示刷新，避免覆盖另一页的新内容。

## 开发与发布

`site/` 是完整静态站点，所有资源使用相对路径，兼容 GitHub Pages 子目录。通过 HTTP 本地服务器预览；离线功能需要 localhost 或 HTTPS。

```sh
node --test tests/core.test.mjs tests/player.test.mjs
```

GitHub Actions 在 `main` 推送后运行测试并发布 `site/` 到 Pages。发布新版本修改 `sw.js` 的 shell 缓存版本；已打开的客户端会提示更新，个人数据保留。

### 在线美式语音配置

Cloudflare Worker 代理将 ElevenLabs API Key 保存在服务端。部署后，在每台设备设置页填写 Worker HTTPS 地址（末尾加 `/tts`）和访问口令。导出完整备份时会包含内置示范音频、已上传音频，以及已经在线生成并保存到本机的音频。不要将 API Key 或访问口令提交到仓库。

```sh
cd worker
npx wrangler login
npx wrangler deploy
npx wrangler secret put ELEVENLABS_API_KEY
npx wrangler secret put ACCESS_TOKEN
```
