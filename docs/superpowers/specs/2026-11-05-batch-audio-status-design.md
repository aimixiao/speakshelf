# 批量语音状态与生成设计

## 意图

让用户能在导入后立即看出每条词句是否已有可复用音频，并用一次点击把所有缺少音频的新词句生成并保存到本机。

## 目标

- 词句卡片显示固定音频、已有音频、待生成语音或设备即时朗读状态。
- 设置页显示新增词句的已生成/待生成统计。
- 使用当前在线 TTS 串行生成所有待生成语音，逐条保存到现有 IndexedDB 音频备份。
- 已有音频自动跳过；单条失败不阻塞后续条目，允许再次点击继续。

## 非目标与约束

- 不改变现有备份格式、词句 ID 或 IndexedDB 数据结构。
- 不在导入操作中自动调用 TTS，避免导入变慢或意外消耗额度。
- 内置 18 条固定 MP3 不参与批量生成。
- 没有在线 TTS 配置时，只显示设备朗读/待配置提示，批量按钮不可用。

## 实现选择

采用设置页手动批量生成方案。批量队列放在独立的纯逻辑模块中，按词句顺序串行调用生成器并通过回调报告进度；应用层负责连接在线 TTS、IndexedDB 保存和界面更新。Service Worker 与模块查询版本一起升级，避免手机继续命中旧缓存。
